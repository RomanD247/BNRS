# User Guide: Background Scanner Feature

## What's New?

The scanner now works in the background when selecting a user during the rental process. You no longer need to click any buttons - just scan!

## How to Use

### Renting Equipment with Scanner:

1. **Click "Scan to Rent"** button on the main page
2. **Scan the device** you want to rent
3. The "Select User" dialog appears
4. **Scan your personal code** - the scanner works automatically in the background!
5. Your user is automatically selected
6. Confirm the rental

### Alternative: Manual Selection

If you prefer, you can still select a user manually from the dropdown list in the dialog.

## Scanner Modes

The system supports two scanner modes:

- **USB HID Mode**: Scanner works in background (recommended)
- **Keyboard Mode**: Scanner types like a keyboard

Both modes work seamlessly with the new background scanning feature.

## Troubleshooting

**Scanner not working?**
- Check scanner connection
- Verify scanner is configured correctly
- Try manual selection from dropdown

**User not found?**
- Ensure user has a registered code
- Try scanning again
- Use manual selection as backup
