# Изменения в системе генерации Data Matrix кодов

## Что было изменено

Улучшен пользовательский интерфейс для генерации Data Matrix кодов. Теперь выбор папки для сохранения происходит непосредственно при нажатии кнопки генерации, а не заранее.

## Конкретные изменения

### main.py

1. **Удален метод `select_output_directory()`** - больше не нужен предварительный выбор папки

2. **Изменен метод `generate_users_codes()`**:
   - Добавлен вызов диалога выбора папки в начале метода
   - Удалена проверка предварительно выбранной папки
   - Улучшены сообщения пользователю с указанием выбранной папки

3. **Изменен метод `generate_equipment_codes()`**:
   - Добавлен вызов диалога выбора папки в начале метода
   - Удалена проверка предварительно выбранной папки
   - Улучшены сообщения пользователю с указанием выбранной папки

4. **Упрощен интерфейс диалогового окна**:
   - Удалена кнопка "Выбрать папку для сохранения"
   - Удален элемент отображения выбранной папки
   - Добавлено информационное сообщение о том, что диалог выбора папки откроется при нажатии кнопки
   - Уменьшена высота диалогового окна с 300px до 250px

5. **Удалено поле `self.output_directory`** из конструктора класса

### Обновлены тесты

1. **test_gui_instantiation.py** - удалена проверка метода `select_output_directory`
2. **test_integration.py** - удалена проверка метода `select_output_directory`

## Преимущества изменений

1. **Улучшенный UX**: Пользователю не нужно заранее выбирать папку - он может сразу нажать нужную кнопку генерации
2. **Упрощенный интерфейс**: Меньше элементов управления, более интуитивный процесс
3. **Гибкость**: Можно выбирать разные папки для пользователей и оборудования
4. **Меньше ошибок**: Исключена возможность забыть выбрать папку перед генерацией

## Как это работает теперь

1. Пользователь открывает диалог генерации кодов
2. Нажимает кнопку "Генерировать коды для всех пользователей" или "Генерировать коды для всего оборудования"
3. Автоматически открывается диалог выбора папки
4. После выбора папки начинается генерация кодов
5. Пользователь получает уведомление с результатами и указанием папки сохранения

Все существующие функции генерации кодов остались без изменений.
