# Requirements Document

## Introduction

Данная функция добавляет возможность редактирования записей аренды в Admin Panel системы управления арендой оборудования. Администратор сможет просматривать все записи аренды и редактировать их основные поля для корректировки данных или исправления ошибок.

## Glossary

- **Admin Panel**: Административная панель в main.py (строка 380), доступная после ввода пароля
- **Rental System**: Система управления арендой оборудования WenglorMEL
- **Rental Record**: Запись аренды из таблицы Rental(Base) с полями id_re, user_id, equipment_id, rental_start, rental_end, comment
- **Database**: База данных SQLite (rental.db) с таблицами пользователей, оборудования и аренды
- **Edit Dialog**: Диалоговое окно для редактирования данных записи аренды
- **CRUD Module**: Модуль crud.py с существующими функциями get_rental, get_all_rentals и новой функцией update_rental

## Requirements

### Requirement 1

**User Story:** Как администратор, я хочу иметь кнопку для редактирования записей аренды в Admin Panel, чтобы получить доступ к функции управления данными аренды

#### Acceptance Criteria

1. WHEN администратор открывает Admin Panel, THE Rental System SHALL отображать кнопку "Edit Rentals" среди других административных кнопок
2. THE кнопка "Edit Rentals" SHALL иметь соответствующую иконку и подпись для идентификации функции
3. THE кнопка "Edit Rentals" SHALL быть размещена в том же стиле, что и другие кнопки Admin Panel (100x100 пикселей)
4. WHEN администратор нажимает на кнопку "Edit Rentals", THE Rental System SHALL открыть диалог со списком всех записей аренды

### Requirement 2

**User Story:** Как администратор, я хочу видеть список всех записей аренды, чтобы выбрать конкретную запись для редактирования

#### Acceptance Criteria

1. WHEN открывается диалог редактирования записей аренды, THE Rental System SHALL отобразить таблицу со всеми записями из таблицы Rental
2. THE таблица записей аренды SHALL содержать колонки: ID записи, имя пользователя, название оборудования, дата начала аренды, дата окончания аренды, комментарий
3. THE Rental System SHALL использовать существующую функцию get_all_rentals из crud.py для получения данных с загруженными связями
4. WHEN в системе нет записей аренды, THE Rental System SHALL отобразить сообщение "Нет записей аренды"
5. THE диалог со списком записей SHALL иметь кнопку закрытия для возврата в Admin Panel

### Requirement 3

**User Story:** Как администратор, я хочу выбрать конкретную запись аренды из списка, чтобы открыть форму редактирования для этой записи

#### Acceptance Criteria

1. WHEN администратор нажимает на строку в таблице записей аренды, THE Rental System SHALL открыть диалог редактирования для выбранной записи
2. THE Rental System SHALL передать все данные выбранной записи в форму редактирования
3. THE форма редактирования SHALL отображать текущие значения всех редактируемых полей
4. THE диалог редактирования SHALL иметь заголовок с указанием ID редактируемой записи
5. THE Rental System SHALL закрыть диалог со списком записей при открытии формы редактирования

### Requirement 4

**User Story:** Как администратор, я хочу редактировать поля записи аренды (кроме id_re), чтобы исправить данные или внести изменения

#### Acceptance Criteria

1. THE форма редактирования SHALL содержать поле выбора пользователя (user_id) с выпадающим списком всех активных пользователей
2. THE форма редактирования SHALL содержать поле выбора оборудования (equipment_id) с выпадающим списком всего активного оборудования
3. THE форма редактирования SHALL содержать поле ввода даты и времени начала аренды (rental_start)
4. THE форма редактирования SHALL содержать поле ввода даты и времени окончания аренды (rental_end), которое может быть пустым
5. THE форма редактирования SHALL содержать текстовое поле для комментария (comment)
6. THE поле id_re SHALL быть отображено только для информации и не должно быть редактируемым
7. THE форма редактирования SHALL иметь кнопки "Сохранить" и "Отмена"

### Requirement 5

**User Story:** Как администратор, я хочу сохранить изменения в записи аренды, чтобы обновить данные в базе данных

#### Acceptance Criteria

1. WHEN администратор нажимает кнопку "Сохранить", THE Rental System SHALL валидировать введенные данные
2. THE Rental System SHALL проверить, что выбран существующий пользователь и оборудование
3. THE Rental System SHALL проверить, что дата начала аренды не позже даты окончания (если указана)
4. WHEN валидация успешна, THE Rental System SHALL использовать новую функцию update_rental в crud.py для обновления записи
5. THE функция update_rental SHALL обновлять поля user_id, equipment_id, rental_start, rental_end и comment
6. WHEN обновление успешно, THE Rental System SHALL отобразить уведомление об успешном сохранении
7. THE Rental System SHALL закрыть диалог редактирования после успешного сохранения
8. WHEN происходит ошибка при сохранении, THE Rental System SHALL отобразить сообщение об ошибке без закрытия диалога

### Requirement 6

**User Story:** Как администратор, я хочу отменить редактирование записи аренды, чтобы вернуться к списку без сохранения изменений

#### Acceptance Criteria

1. WHEN администратор нажимает кнопку "Отмена", THE Rental System SHALL закрыть диалог редактирования без сохранения изменений
2. THE Rental System SHALL вернуться к диалогу со списком записей аренды
3. THE Rental System SHALL не вносить никаких изменений в базу данных при отмене
4. WHEN администратор закрывает диалог редактирования через кнопку закрытия, THE Rental System SHALL действовать как при нажатии "Отмена"
